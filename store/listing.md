## Detailed description (paste into the "Description" field)

**GradeFlow** puts a full grade overview panel right inside SmartSchool. Click the GradeFlow button in the sidebar and all your results show up in a clean, interactive table.

**Grade overview**
• All your grades across every period, sorted by subject
• Color-coded cells so you can immediately spot weak and strong results
• Hover any grade to see the score, contribution, and weighted details
• Sticky subject column with SmartSchool's own subject icons
• Bottom bar with your overall percentage, total points, subject count, best subject, and a progress bar

**Weighting methods**
• **Points** - plain scored/max percentage
• **Hour-weighted** - set lesson hours per subject and your average gets weighted accordingly
• **Formula** - define your own period groups with custom weights (e.g. 40% Semester 1 + 60% Semester 2), drag to reorder

**Periods**
• Auto-detects all your SmartSchool periods (semesters, trimesters, exams, etc.)
• Switch between individual periods or view everything combined in "Alle"
• Duplicates across periods are handled automatically

**Best subject**
• Shows your top subject by grade percentage or by hour-weighted value

**Appearance and language**
• Dark and light theme (with anti-flash so no white screen when loading)
• Dutch, English, and French
• Full custom language editor - change any string you want, import/export as JSON
• Choose your decimal separator (comma or period) and how many decimal places to show

**Subject icons**
• Pulled straight from SmartSchool's own icon set
• Click any icon in the table to swap it for an emoji
• 50+ built-in keyword rules, fully editable, with a reset option

**Personalisation**
• Change your display name on SmartSchool
• Replace your profile picture with any image (drag and drop or file picker)
• Fake message counter (0-9999)
• Fake notification counter (0-9999)
• Fake news counter (0-9999)

**Help**
• Built-in help panel explaining every feature and shortcut
• Links to GitHub and the Chrome Web Store review page

**Arcade - 6 hidden games (press F8)**
• **GradeStack** - Tetris with grade-themed pieces
• **GradeSnake** - snake game with levels, good grades make you grow, bad ones shrink you
• **Grade 2048** - merge weak grades until you hit 20/20
• **GradeSweeper** - minesweeper where the mines are failing grades (3 difficulties)
• **GradeMemory** - flip and match grade card pairs (easy/medium/hard)
• **GradeShooter** - bubble shooter with grade-colored bubbles, clear mode and endless mode

All games use your actual grades when available, track your personal best, and have animated previews in the menu.

**Peer-to-peer chat (press F7)**
• Opt-in overlay chat with other GradeFlow users, fully off by default
• Direct browser-to-browser over WebRTC, no server, no account
• Host generates one invite link per friend (room code is baked in); you share each link yourself (Discord, etc.). Each invite slot doubles as a kickable seat.
• Survives page navigations on SmartSchool so your chat stays alive while you browse
• Rooms cap at 8 people (host + 7)
• Messages are kept in memory only (max 60, wiped when the room closes). GradeFlow itself never writes chat to disk, but anything another peer sends you ends up in their browser too, and they can copy or save it like any other message.
• Mandatory warning screen on first use: your LAN/public IP is visible to every peer, there is no moderation, and any peer can pick any nickname and send anything. Only chat with people you actually know.
• Fully translated (Dutch, English, French)

**Keyboard shortcuts**
• F7 - open/close the chat overlay
• F8 - open/close the arcade
• Esc - close settings, arcade, or current game
• P - pause game
• R - restart game
• Arrow keys / WASD - game controls
• Z - rotate (GradeStack)

**Privacy**
GradeFlow reads your grades from SmartSchool's own API (you need to be logged in) and keeps everything locally in your browser. No grade data ever leaves your machine. No analytics, no tracking. The optional P2P chat connects directly between browsers using WebRTC and makes a single STUN request (Google's public STUN) to establish the connection, no chat content is ever sent to us or any third-party server. See the full privacy policy for details.
